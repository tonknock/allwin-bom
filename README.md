# ALLWIN BOM

หน้าเว็บคำนวณวัตถุดิบ (ท่อ แผ่นเหล็ก เพลา สกรู) ตาม Main Assembly รุ่น JT2511LW และ JT2512LW

## วิธีอัพเดตเมื่อมี BOM รอบใหม่
1. เปลี่ยนชื่อไฟล์ HTML รอบใหม่เป็น `index.html`
2. ในหน้า repository กด **Add file → Upload files** แล้วลากไฟล์ `index.html` มาวาง
3. กด **Commit changes**
4. รอประมาณ 1-2 นาที ลิงก์เดิมจะแสดงข้อมูลใหม่
